# V2 — draw worker, batch parts, mesh fail-soft

V1 called the official `draftwright` CLI. V2 still never mixes CAD stacks in one Python process. The new drawing path is a **worker script** executed *inside* the locked draftwright environment:

```
.scad  →  uv run scad2step  →  .step  →  uv run python scripts/v2_draw_worker.py  →  PDF / SVG
```

`scad2drawing` itself still has no CAD imports. Only `scripts/v2_draw_worker.py` may `from draftwright import build_drawing`, and only when launched with `uv run --directory <draftwright clone>`.

## What shipped

| Flag / path | Default | What it does |
|---|---|---|
| `--draw worker` | yes | Import `draftwright.build_drawing` in the draw env (`auto_dims=`). |
| `--draw cli` | | V1 official CLI (no `auto_dims`). |
| `--parts frame,shaft` | | Loop `-D part=NAME`. Implies `--keep-going`. |
| `--title "Part {part}"` / `--number DWG-{part}` | | Substituted per job. Bare `DWG-001` becomes `DWG-001`, `DWG-002`, … |
| `--on-mesh warn` | yes | Surface mesh-fallback lines, still auto-dimension. |
| `--on-mesh views-only` | | Worker `--no-auto-dims` (views + title block). |
| `--on-mesh skip-draw` | | Write STEP + `*.MESH_FALLBACK.txt`, skip drawing. |
| `--on-mesh fail` | | Non-zero exit when scad123d mesh-fallbacks. |
| `--keep-going` | implied by `--parts` | Finish the batch; exit 1 if any job failed. |

Mesh hits also write `{stem}.MESH_FALLBACK.txt` and stamp `scad2drawing.mesh_fallback` on the JSON report when the worker can write one.

After a drawing, the CLI reads `{stem}.draftwright.json` (stdlib JSON, no CAD import) and prints lint `status=`, error/warning counts, and the first few error/warning codes. If draftwright’s report status is `needs-attention`, that job is counted as `needs-attention` in the batch line. That does **not** fail the run (drawings were still written). Default `--formats` is `pdf,svg` so a human can edit the SVG.

## Examples

```bash
# V2 default: worker inside the draftwright lockfile
scad2drawing convert samples/plate.scad -o out --title "Plate"

# Batch selector (samples/selector.scad)
scad2drawing convert samples/selector.scad -o out \
  --parts frame,shaft --title "{part}" --number "DWG-{part}"

# Known hull() fallback: views only, no noisy auto-dims
scad2drawing convert samples/hull_fallback.scad -o out --on-mesh views-only

# Stay on the V1 CLI
scad2drawing convert samples/cube.scad -o out --draw cli
```

## Not in this slice

- Mixing scad123d and draftwright in one Colab kernel (build123d pins still conflict on Py 3.12)
- GD&T / `Sheet` authoring beyond `auto_dims=False`
- Onshape mates, assembly balloons, BOM

`--draw cli` remains the conservative AGPL path if you do not want the in-env import.
